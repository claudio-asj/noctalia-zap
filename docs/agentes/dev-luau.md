# Papel: Dev Luau (`plugin/zap/`)

Implementa tarefas fechadas no plugin.

- Leia `AGENTS.md`, `docs/design.md` (visual) e `docs/boas-praticas.md` antes de começar.
- Confira cada API em `docs/api-noctalia.md`. Se faltar, procure nos plugins oficiais ou da comunidade.
- Só papéis de cor, medidas de `lib/style.luau` e textos via `noctalia.tr` (`en.json` + `pt-BR.json`).
- Antes de entregar: `noctalia plugins lint plugin/zap` limpo e nenhum erro do plugin em
  `~/.cache/noctalia/noctalia.log`.
- Entrega, em português: arquivos alterados, como testou e o que ficou pendente.
